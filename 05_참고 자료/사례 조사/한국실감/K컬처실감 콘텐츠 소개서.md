# 3 키오스크 콘텐츠

## 3.1 공통 구성

출처: 원문 4~9쪽.

| 콘텐츠 | 소개 방향 | 주요 체험 |
|---|---|---|
| 한글 | 한글의 역사와 의미 | 디지털 휴먼 안내, 역사 카드 |
| 음식 | 취향에 맞는 한국 음식 | 질문 응답, 추천 결과와 음식 정보 |
| 한국화 | 작품 감상과 설명 | AI 화가 안내, 갤러리의 작품 선택 |
| K-POP | 시대별 이야기와 음악 | AI 아이돌 안내, 한국어 학습, 음악 선택과 감상 |
| 고궁 | 궁궐과 전통문화 | AI 큐레이터 안내, 한국어 퀴즈와 문화 탐색 |

- 화면 안내에 따라 정보를 살펴보거나 질문에 답하는 방식.
- 삽입 화면에는 홈, 이전과 다음 이동, 음성 재생, 마이크 등 기능별 조작 요소 표시. 모든 콘텐츠가 같은 조작 요소를 제공한다고 단정하지 않음.
- 일부 AI 인물 안내 화면에는 녹음 후 다시 눌러 답변을 제출하라는 영문 안내 표시. 자유 대화의 범위, 음성 인식 방식과 실제 응답 성능은 원문 설명만으로 확인 불가.

## 3.2 한글

출처: 원문 5쪽.

### 3.2.1 내용과 화면 예시

- 디지털 휴먼의 설명과 역사 카드를 통해 한글의 배경과 의미 소개.
- 안내 화면에는 한국 여행 가이드 유나의 인사 예시 표시.
- 역사 카드 예시는 한글 창제를 소개하는 `Hangeul created` 화면. 세종과 훈민정음에 관한 영문 설명, 다시 듣기와 이전 및 다음 이동 표시.

### 3.2.2 체험 순서

1. 디지털 휴먼의 안내 듣기.
2. 역사 카드를 넘기며 한글의 역사와 의미 살펴보기.

## 3.3 음식

출처: 원문 6쪽.

### 3.3.1 내용과 화면 예시

- 화면의 질문에 답하면 취향에 맞는 한국 음식과 음식 정보 제시.
- 예시 질문은 메뉴에 낯선 음식이 있을 때 어떻게 반응하는지 선택하는 내용. 바로 시도, 직원에게 문의, 다른 사람의 주문 관찰, 사진을 보고 선택하는 보기 제시.
- 추천 결과 예시는 김치. 음식 사진, 한글과 영문 명칭, 영문 설명 표시.
- 질문 화면에 `2/9` 진행 표시가 있으나 전체 질문 목록과 추천 규칙은 미제공.

### 3.3.2 체험 순서

1. 취향을 알아보는 질문에 답하기.
2. 추천 음식과 설명 확인.

## 3.4 한국화

출처: 원문 7쪽.

### 3.4.1 내용과 화면 예시

- AI 화가의 안내를 듣고 갤러리에서 한국화 작품을 선택하여 설명과 함께 감상.
- AI 화가 화면의 인물은 영문 대사에서 김홍도로 소개.
- 작품 감상 예시는 `Gonu Nori`. 두루마리 형식의 그림, 영문 설명, 재생 버튼과 돌아가기 버튼 표시.

### 3.4.2 체험 순서

1. AI 화가의 안내 듣기.
2. 갤러리에서 작품 선택.
3. 작품과 설명 감상.

## 3.5 K-POP

출처: 원문 8쪽.

### 3.5.1 내용과 화면 예시

- AI 아이돌의 안내와 한국어 학습을 체험하고 시대별 음악 소개에서 K-POP의 흐름 확인.
- 원하는 곡을 선택하여 감상하는 구성.
- AI 아이돌은 화면의 영문 대사에서 `Mina`로 소개.
- 시대별 음악 화면 예시는 `1st Generation`, `1992 - 1999`로 표시. 곡 선택과 좌우 이동 화면 제시.
- 전체 시대 구분, 수록 곡 목록과 한국어 학습 문항은 원문에 미제공.

### 3.5.2 체험 순서

1. AI 아이돌 안내 듣기.
2. 한국어 학습 체험.
3. 시대별 음악을 살펴보고 곡을 선택하여 감상.

## 3.6 고궁

출처: 원문 9쪽.

### 3.6.1 내용과 화면 예시

- AI 큐레이터의 안내와 한국어 퀴즈를 통해 궁궐과 전통문화 소개.
- 큐레이터 화면의 영문 대사에는 경복궁과 수문장 교대식에 관한 안내 예시 표시.
- 단어 퀴즈 예시는 갓 그림에 맞는 단어를 고르는 화면. 보기로 모자, 가구, 나무와 지도 표시.

### 3.6.2 체험 순서

1. AI 큐레이터 안내 듣기.
2. 한국어 단어 퀴즈 등 학습 체험.
3. 궁궐과 전통문화 탐색.

출처: 원문 11쪽.

### 4.2.1 내용과 결과

- 글씨체, 색상과 장식을 선택하여 한글 작품 완성.
- 화면 예시는 블록으로 이름을 조합하는 장면과 글씨체 및 장식을 선택한 결과.

### 4.2.2 체험 순서

1. 자모 블록으로 한글 이름 만들기.
2. 글씨체 선택.
3. 색상과 장식으로 꾸미기.

## 4.3 한국 요리 만들기

출처: 원문 12쪽.

### 4.3.1 내용과 결과

- 전용 부채를 테이블 위에서 움직여 재료와 조리 도구 조작.
- 손님의 주문에 맞춰 음식을 만들고 전달하는 게임.
- 게임 결과에서 점수 확인. 삽입 화면에는 손님 주문, 재료와 조리 공간 및 타이머 표시.
- 화면에 나온 남은 시간을 전체 체험의 고정 시간으로 해석하지 않음. 세부 조리법, 점수 계산과 제한 시간 규칙은 원문에 미기재.

### 4.3.2 체험 순서

1. 손님 주문 확인.
2. 부채를 움직여 재료 준비와 조리.
3. 완성한 음식 전달.
4. 게임 결과에서 점수 확인.

## 4.4 한국화 그리기

출처: 원문 13쪽.

### 4.4.1 내용과 결과

- 사용자가 직접 그린 그림을 AI로 한국화 스타일로 변환.
- 전용 용지를 테이블의 인식 영역에 놓는 방식.
- 완성된 작품을 풍등에 담아 화면에 띄우는 연출. 표지에도 이 콘텐츠의 실제 화면이라고 표시한 풍등 이미지 사용.
- 인쇄, 사진 다운로드와 외부 전송 기능은 해당 콘텐츠 설명에 미기재.

### 4.4.2 체험 순서

1. 전용 용지에 그림 그리기.
2. 용지를 테이블의 인식 영역에 올리기.
3. AI가 그림을 한국화 스타일로 변환.
4. 작품을 담은 풍등 연출 감상.

# 5 키오스크 연계 포토타임

출처: 원문 14쪽.

## 5.1 기능과 적용 콘셉트

- 한국문화 체험을 마친 뒤 사진을 촬영하고 해당 콘텐츠 콘셉트에 맞는 AI 이미지로 변환하는 연계 체험.
- 완성된 사진을 모바일 앱으로 받아볼 수 있다고 설명.
- 삽입 이미지는 한국화 포토타임 기획서 화면 예시라고 명시. 완료된 구현이나 운영 실적과 구분.

| 연계 콘텐츠 | 사진 콘셉트 |
|---|---|
| 한국화 | 수묵화 스타일 |
| K-POP | K-POP 스타 콘셉트 |
| 고궁 | 조선 왕실 복장 콘셉트 |

## 5.2 체험 순서와 화면 예시

1. 사진 촬영.
2. AI 이미지 변환.
3. 변환 결과 확인.
4. 모바일 앱 전송.

- 촬영 화면에는 중앙에 서도록 안내하는 문구와 촬영 카운트 표시.
- 결과 화면에는 변환 이미지, QR 다운로드 안내, 다시 촬영과 종료 버튼 표시.
- 본문은 모바일 앱 수령으로 설명하고 화면은 QR 다운로드로 안내. 두 방식의 관계, 앱 이름과 설치 필요 여부는 원문에 미기재.
- 한글과 음식에 적용하는 포토타임 콘셉트는 이 페이지에 별도 설명 없음.

# 6 추가 제품 포토그램AI

## 6.1 제품 개요

출처: 원문 15쪽.

- 사진 촬영, AI 스타일 변환과 현장 출력을 제공하는 포토 키오스크.
- 원하는 스타일로 촬영한 사진을 변환하고 결과를 골라 사진이나 포토카드로 출력.
- QR코드로 디지털 사진 다운로드.
- 행사와 브랜드에 맞춘 프레임 및 화면 구성.
