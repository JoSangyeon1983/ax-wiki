# 3. 근거 단위와 초안 구조 대응

| 초안 구조 | 사용한 근거 ID | 묶은 이유 |
|---|---|---|
| 콘텐츠 형식 | E01, E02 | 출력 공간, 입력 장치와 게임의 핵심 규칙을 한 문장으로 정의함 |
| 1차년도 시범 콘텐츠 | E03, E05, E06, E09, E10, E13 | 정본의 기술 목표와 회의에서 확인한 실제 자체 데모 운용을 연결함 |
| 통합 기술 검증 | E02, E06, E07, E08, E10 | 다면 출력과 복수 센서가 함께 작동하는 공간 체험 기반을 검증하는 목적을 설명함 |
| 산학 연구와 교육 연계 | E04, E11, E13, E14 | 자체 데모를 공동연구, 사용성 평가와 후속 PBL의 입력으로 활용하는 목적을 설명함 |
| 후속 실증과 확장 | E04, E11, E12, E13 | 전시와 파일럿 실증 및 후속 케이브 콘텐츠로 이어지는 활용 방향을 설명함 |

- **설계 추가**: `통합 기술 검증`과 `후속 실증과 확장`은 원문 절 제목이 아니라 여러 기관 문서에 흩어진 목적을 기획서 독자 관점에서 묶은 라벨임
	- 원자료는 Cave Super Ball이라는 이름을 1차년도 자체 데모와 직접 연결하지 않음. 이 연결은 본 초안에서 정한 기획상 배치임
	- 코드 분석은 실행, 빌드와 센서 연동 시험을 수행하지 않았음. 통합 시험과 후속 활용은 완료 사실이 아니라 개발 목적으로 서술함
- **제외**:
	- 정량 성능 목표는 Cave Super Ball 한 콘텐츠의 확정 성능으로 볼 근거가 부족하여 개요에서 제외함
	- 총기 인식과 현실 물체 동기화는 후속 연차 방향이므로 현재 콘텐츠 정의에서 제외함
	- 햅틱과 생성형 AI는 전체 과제 범위에는 포함되지만 현재 코드에서 Cave Super Ball의 핵심 상호작용으로 확인되지 않아 정의에서 제외함
- **대안 구조**: 기술, 교육, 사업화의 세 갈래로도 나눌 수 있으나, 현재 개발물이 무엇을 먼저 검증하고 어디로 이어지는지를 보여 주기 위해 시범, 검증, 연계, 확장 순서를 채택함
