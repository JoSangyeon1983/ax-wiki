# 1 목적과 상태

- 목적: 개조식 작성 시 `~임`, `~함`, `~음`으로 반복 종결하는 방식을 제한하기 위한 작성 규칙 수정안 정리.
- 현재 상태: 검토안 문서화 완료, 실제 규칙 적용 보류.
- 사용자 지시: 수정 위치와 방법을 먼저 보고하고 적용하지 않도록 요청. 이후 다른 작업을 위해 제안 내용을 문서로 보존하도록 요청.
- 재개 지점: 아래 교체 문구를 검토한 뒤 사용자의 적용 지시에 따라 규칙 수정.

# 2 현재 규칙과 수정 이유

대상은 [작성 규칙: 간결성과 종결](<../../00_시스템/01_규정/작성 규칙.md#321-간결성과-종결>)의 다음 문구.

> **명사형 종결**: 개조식 문장의 끝을 `~음`, `~임`, `~함` 또는 명사 자체로 종결.

- 현재 규칙에서 `~음`, `~임`, `~함`을 명시적으로 허용.
- 개조식의 항목별 간결한 정리 방식과 서술어를 명사화한 종결 방식의 구분 필요.
- `명사형 종결`만 지정하면 `~음`, `~ㅁ`도 포함하므로 `명사 또는 명사구 종결`로 기준 구체화.

# 3 수정 위치와 교체 문구

## 3.1 간결성과 종결

- 수정 파일: `00_시스템/01_규정/작성 규칙.md`.
- 수정 절: `3.2.1 간결성과 종결`.
- 수정 방법: 기존 `명사형 종결` 불릿을 아래 세 항목으로 교체. 기존 간결성 원칙과 한 항목의 내용 범위 규칙 유지.

```markdown
- **종결 방식**: 개조식 항목은 명사 또는 명사구로 종결.
- **서술어 명사화 제한**: `~임`, `~함`, `~음`, `~됨` 등 서술어를 명사화한 종결형 사용 금지.
- **의미 보존**: 종결형을 바꿀 때 주체, 조건, 부정과 확인 상태 유지. 단순히 끝부분만 삭제하여 의미가 불완전해지는 표현 금지.
```

## 3.2 최종 점검 항목

- 수정 절: 같은 파일의 [작성 규칙: 내용과 문체](<../../00_시스템/01_규정/작성 규칙.md#61-내용과-문체>).
- 수정 대상: `개조식 문장의 명사형 종결, 항목 계층, 6개 이상 항목의 헤더 그룹화 여부 확인.` 항목.
- 수정 방법: 기존 종결 점검을 아래 첫 항목으로 바꾸고 항목 계층과 그룹화 점검은 둘째 항목으로 보존. 작성 기준과 검수 기준의 일치.

```markdown
- 개조식 항목의 명사 또는 명사구 종결 여부, 금지한 서술어 명사화 종결형의 사용 여부 확인.
- 항목 계층과 6개 이상 항목의 헤더 그룹화 여부 확인.
```

# 4 표현 예시

| 기존 표현 | 수정 예시 | 유지할 의미 |
|---|---|---|
| 여러 사용자가 공을 조작하는 게임임 | 다중 사용자 공 조작 게임 | 여러 사용자와 공 조작 |
| 입력 조건을 확인함 | 입력 조건 확인 | 입력 조건에 대한 확인 |
| 비활성 상태에서는 입력을 처리하지 않음 | 비활성 상태의 입력 처리 제외 | 비활성 조건과 처리 제외 |

- 금지 대상은 서술어의 종결 방식. `도움` 같은 일반 명사를 끝 글자만으로 금지하는 방식 지양.
- 표현을 줄이는 과정에서 사실의 상태, 적용 범위와 부정 의미가 바뀌는지 문맥 검토.

# 5 유지할 규칙과 적용 범위안

- [작성 규칙: 원형 보존](<../../00_시스템/01_규정/작성 규칙.md#12-원형-보존>)의 원문 인용, 코드, URL, 파일 경로 등의 예외 유지.
- [작성 규칙: 의미 전달](<../../00_시스템/01_규정/작성 규칙.md#323-의미-전달>)의 주체, 조건과 상태 보존 및 짧은 문단 허용 유지.
- 규칙 수정 대상은 현재 AX 위키의 `작성 규칙.md` 한 파일. AGENTS.md에서 해당 규칙을 참조하므로 동일한 종결 규칙의 중복 기재 불필요.
- 적용 범위 제안: 규칙 적용 후 새로 작성하거나 사용자가 수정을 요청한 내용에 적용. 기존 문서의 일괄 변경은 별도 요청 범위에서 판단.

# 6 적용 재개 체크리스트

- [ ] 사용자 적용 지시와 수정 범위 확인.
- [ ] 작성 규칙의 간결성과 종결 항목 및 최종 점검 항목 수정.
- [ ] 의미 전달과 원형 보존 규칙의 유지 및 표현 예시의 일치 확인.
- [ ] 규칙 문서의 수정일 갱신, 헤더 번호 도구 적용과 링크 검사 및 월별 로그 기록.

- 현재 완료 범위: 수정안 작성과 저장. 위 적용 체크 항목은 미실행 상태.
