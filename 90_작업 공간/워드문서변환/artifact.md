# 3 편집 슬롯

| 위치 | 용도와 처리 |
|---|---|
| `word/document.xml`의 body/tbl[1] 안 회사명 plain text SDT | CELLBIG AI융합본부 표시와 컨트롤을 보존함 |
| 같은 표의 제목과 부제 plain text SDT | 기존 text 노드만 해당 콘텐츠명과 콘셉트 기획서로 교체함. Cave Action과 Cave Super Ball에 적용함. SDT, 바인딩, 문단과 run 속성은 보존함 |
| body/tbl[2]의 작성자와 발행일 SDT | 원문의 작성자와 발행일이 지정되지 않아 텍스트만 비움. 원본 예시의 이름과 날짜를 새 문서의 사실로 사용하지 않음 |
| body/tbl[3] 버전 관리 표 | 헤더와 1개 빈 입력 행을 보존함. 원본 예시 버전과 변경 이력은 비움. 사용자 버전을 임의 부여하지 않음 |
| body/sdt의 목차 | 원본 SDT와 제목 및 마지막 구역 경계 보존. field cache에 입력 문서의 제목 1과 제목 2를 대응함. 원본 TOC 지시어와 점선 및 오른쪽 쪽 번호를 사용함 |
| body/p의 제목 1 개요 | MD의 전체 본문으로 확장함. 원본 제목 및 본문 스타일을 사용함. H1~H3와 표 및 목록은 반복 가능 슬롯임 |
| body/sectPr | 마지막 구역 속성 전체 보존함 |

- 사용자 요청에 따라 프론트매터 전체를 출력에서 제외함. 파일명에서 문서 제목을 정하며 본문 내용, 미정 사항과 초안 및 승인 대기 문구는 원문 그대로 유지함.
- 빈 작성자와 발행일 슬롯은 표시 없는 공백을 사용해 Word의 입력 안내문 출력을 방지함. 예시의 이름과 날짜를 새 문서의 사실로 사용하지 않음.
- 표지의 문서 속성 바인딩에 대응하는 `docProps/core.xml`의 제목, 부제와 작성자 및 `customXml/item1.xml`의 발행일을 함께 갱신함. 다른 customXml, 도형, 테마, footer 및 SDT 속성은 보존함.
- 목차의 참조 대상을 각 본문 제목의 고유 bookmark로 연결함. Word의 실제 페이지 계산으로 캐시의 쪽 번호를 갱신함. 열 때 필드를 강제로 갱신하는 updateFields 설정은 추가하지 않음. 이 설정은 최초 변환본에서 열기 경고를 유발하여 제거함.

# 4 보존과 검증 계약

- 편집 허용 part: `word/document.xml`, `word/_rels/document.xml.rels`, `word/numbering.xml`, `docProps/core.xml`, `customXml/item1.xml`, `[Content_Types].xml`. 실제 내용이 변하는 part만 재작성함. `word/settings.xml`은 원본 바이트로 보존함.
- 새 part: 본문에 실제 삽입한 PNG 파일만 추가함. 기존 관계와 numbering 정의는 그대로 두고 필요한 새 항목만 추가함.
- 나머지 모든 part는 reference_inventory의 원본 바이트와 일치해야 함. styles, theme, footer, 표지 도형과 동봉 미디어 및 preserve-only customXml을 포함함.
- 필드 감사에서 외부 관계와 외부 파일을 읽는 필드가 없는지 확인함. 열기 검증은 Word의 경고 표시를 활성화한 상태로 수행함. 읽기 전용 PDF 출력 성공만으로 열기 경고 부재를 판단하지 않음.
- 구역 2개의 속성, 표지 그림의 anchor와 geometry, SDT 속성 및 바인딩과 기존 관계의 보존을 대조함.
- MD의 모든 본문 블록을 순서대로 대응함. Cave Action의 표 4개와 이미지 2개, Cave Super Ball의 표 6개와 이미지 2개를 각각 대조함. 이미지 바이트 해시와 종횡비를 확인함.
- 원본과 생성본의 전 쪽 렌더링을 열람하여 글자 및 표 잘림, 고립 제목, 번호 중복, 이미지 왜곡과 페이지 번호를 확인함. 빈 버전 입력란은 의도된 빈 슬롯으로 판단함.
- 테스트 구현은 현재 입력의 H1~H3, 불릿, 번호 목록, 문단, Markdown 표, 굵게, 코드 문자열과 HTML img 범위를 지원함. 미지원 구문을 발견하면 생략하지 않고 오류로 중단함.
