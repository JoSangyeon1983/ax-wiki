# 1 수행 과정 및 수행 내용

## 1.1 다중 프로젝터 콘텐츠 시뮬레이션 기술 개발

### 1.1.1 가상 프로젝션 시뮬레이터 개발

- Throw Ratio(투사거리/영상폭), 수직, 수평 렌즈 시프트로 가상 스크린에 도달면을 그리는 광학 시뮬레이터를 개발 완료
- 키스톤은 평면 호모그래피로 보정하고, 거리 제곱 역수 감쇠와 광속 마스크로 밝기 분포를 재현하여 현장 설치 전 시야각·투사 위치를 확인하도록 구축 완료
- 다수 프로젝터를 같은 가상 공간에 두고 투광 각도, 도달면, 중첩 구간을 시각화하는 간섭 시뮬레이션을 개발 완료
- 한 면의 출력이 2대 이상이면 중첩 구간에 기하 워프와 휘도 블렌드를 적용하는 소프트웨어 엣지블렌딩을 구축 완료
- 물리 디스플레이 식별자로 출력을 고정하여 재연결 이후에도 동일 프로젝터를 추적하도록 개발 완료
- 가상 프로젝터 배치 기능을 구현한 시뮬레이션 소프트웨어를 가시적 결과물로 산출

### 1.1.2 센서-프로젝션 공간 구축 도구 개발

- 레이저 센서 검색과 배치, 빈 배경 기록, 격자 캘리브레이션, 실제 터치 확인을 한 흐름으로 묶은 공간 구축 도구를 개발 완료
- 배경 잔차로 전경을 분리한 뒤 격자 타겟을 관측하고, 유사변환과 어파인 및 그리드 변환 중 재투영 오차가 작은 모델로 센서 좌표를 스크린 좌표로 산출하여 OSC로 전달하도록 구축 완료
- 가상 공간에 레이저 센서와 프로젝터를 사전 배치하고, 스크린과 출력 및 센서 구성을 설치 프로필로 저장하고 복원하는 공간 설계 기능을 개발 완료
- 케이브(다면 벽) 및 키즐(벽면+바닥면)은 면 단위 순차 보정으로 처리하고, 면 전환 시에도 엣지블렌딩 이음새와 터치 좌표가 유지되도록 구축 완료
- 가상 프로젝트 및 센서 배치 기능을 구현한 시뮬레이션 소프트웨어를 가시적 결과물로 산출

## 1.2 저조도 조명 다중 투사 공간에서 단순한 인터랙션이 가능한 콘텐츠 개발

### 1.2.1 미디어 아트 기반 시범 콘텐츠 구현

- 미디어 아트 기반 다중 투사 및 다중 인식 시범 연출 콘셉트를 선정
- 레이저 센서 거리 스캔의 배경 잔차로 저조도 사용자 위치를 추정하는 인식 파이프라인을 개발 완료
- 벽면 및 바닥면 다중 프로젝션과 터치 좌표를 같은 스크린 좌표로 정합하여 케이브와 키즐에서 투사와 인식이 같이 동작하도록 구축 완료
- 실터치 좌표에 시각과 청각 반응이 이어지는 시범 콘텐츠 SW를 산출. 실시간 인터랙션 경로 2종(단일 사용자 위치 및 접촉 매핑, 다중 사용자 동시 센싱)을 구축 완료
- 다수 레이저 센서 관측을 시간 정합하여 교차 및 근접 입력의 이중 인식을 억제하는 다인 인식기를 개발 완료
- 인체 간, 인체-객체 인터랙션은 다수 접촉점 OSC 전달 및 객체 교차 판정 경로를 구축. 연출 본편은 마일스톤 기간 내 추진
- 점검 기준인 ‘시범 콘텐츠 1종 개발’ 및 ‘콘텐츠 실행 및 구현 확인’을 충족하는 시범 콘텐츠 소프트웨어 (마일스톤 8.1, 26.07~26.12)를 개발하여 가시적 결과물로 산출

### 1.2.2 Cave Ball 개발

- 여러 사용자의 신체 움직임이 하나의 공에 함께 작용하도록 설계하여 개인 조작을 넘어 협력과 경쟁, 우발적 상호작용이 일어나는 공동 공간 경험을 제공하는 것을 목표로 개발 진행
- 유니티 프로젝트 개발
	- 사용자의 왼손과 오른손이 공에 닿으면 각각 빨간색과 파란색을 부여
	- 사용자의 바닥 접촉 위치와 공이 겹치면 해당 위치를 기준으로 공의 진행 방향 변경
- 시연 및 테스트 진행
	- 미디어 케이브 4개면 프로젝션 확인
	- 공 오브젝트 상호작용 확인

### 1.2.3 Cave Action 개발

- 두 사용자의 점프, 벽면 터치와 위치 이동을 공격과 회피에 연결하고 공격과 방어를 번갈아 수행하도록 설계하여, 상대의 움직임에 대응하며 경쟁하는 공간형 대전 경험을 제공하는 것을 목표로 개발 진행
- 유니티 프로젝트 개발
	- 두 사용자의 점프, 벽면 터치와 위치 이동을 활용한 공격 및 회피 기능 구현
	- 점프에 따른 스캔라인, 벽면 터치에 따른 레이저, 위치 이동에 따른 위험 구역 공격 구현
	- 공격과 방어의 교대, 피격에 따른 체력 감소와 체력 소진에 따른 게임 종료 구현
- 시연 및 테스트 진행
	- 미디어 케이브 4면 영상 출력과 벽면 및 바닥 입력 연동 확인
	- 동작별 공격 발생과 상대방의 회피 및 충돌 판정 확인
	- 공수 교대, 체력 변화와 게임 종료 동작 확인

# 2 목표 달성 수준

## 2.1 다중 프로젝터 콘텐츠 시뮬레이션 기술 개발

- 프로젝터 투사거리, 투사 각도와 렌즈 시프트를 반영한 가상 프로젝션 시뮬레이터 개발 완료
- 다중 프로젝터의 가상 배치, 투사면과 중첩 구간 시각화, 키스톤 보정 및 엣지블렌딩 기능 구현
- 레이저 센서와 프로젝터의 사전 배치, 센서 좌표와 스크린 좌표 정합, 설치 프로필 저장 및 복원 기능을 갖춘 공간 구축 도구 개발 완료

## 2.2 저조도 조명 다중 투사 공간에서 단순한 인터랙션이 가능한 콘텐츠 개발

- 저조도 사용자 위치 인식과 벽면 및 바닥의 다중 투사 및 터치 좌표 정합을 적용한 Cave Ball과 Cave Action 개발
- 실시간 인터랙션 2종 개발을 목표로, 손 접촉에 따른 공 색상 변경과 바닥 접촉에 따른 공 진행 방향 변경 등 2종 이상의 인터랙션 구현 및 작동 확인
- 공간 체험 시범 콘텐츠 1개 제작 계획에 대해 Cave Ball과 Cave Action 총 2개 개발. 현장 시연 및 테스트를 통해 미디어 케이브 4면 출력, 벽면 및 바닥 입력 연동, 공 오브젝트 상호작용과 동작별 공격 및 회피 기능 확인
