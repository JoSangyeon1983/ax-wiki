# 1 자료 범위

- 대상은 2026년도 1단계 공동연구개발기관1 ㈜셀빅의 Cave Ball과 Cave Action임. 공고의 사업 요구, 위키 연구개발계획서의 과제 목표, 개발 코드의 동작, 기존 단계보고서 검토안의 시연 기록을 각각 대조함.
- 문화체육관광부와 한국콘텐츠진흥원의 공고 `KC_2026_003`은 콘텐츠 인력양성 자유공모임. 2026-01-15 수정 공고의 HWP 본문과 제출양식 및 별첨 압축 파일의 목록을 확인함. 확인한 공고와 첨부 목록에는 과제별 지정 제안요구서가 제시되지 않음. 두 콘텐츠의 과제별 수치는 위키 연구개발계획서의 원문 대조본에 있음. [IRIS 콘텐츠 인력양성 공고](https://www.iris.go.kr/contents/retrieveBsnsAncmView.do?ancmId=017556), [2 연구개발의 목표 및 내용: 대조 범위와 한계](<../../01_프로젝트/연구개발계획서/2 연구개발의 목표 및 내용.md#2-대조-범위와-한계>)
- 기존 달성현황 검토안에 인용된 단계보고서 PDF의 4~8쪽과 사용자 확인 사항을 간접 근거로 사용함. 현재 작업공간과 Google Drive 검색에서 해당 PDF 실물을 확인하지 못함. [단계보고서 추진목표별 달성현황 검토안: 입력 자료와 대조 위치](<../단계보고서 작성/단계보고서 추진목표별 달성현황 검토안.md#4-입력-자료와-대조-위치>)

# 2 원문 근거 추출

# 3 성과 항목과 비교 대상

두 콘텐츠는 같은 과제 목표에 대응하며, 입력이 게임 안에서 어떤 상태를 바꾸는지를 기준으로 두 항목을 구성함. E2와 E3은 같은 가상 공에 작용하므로 하나의 성과로 묶고, E4는 상대 참가자의 대응을 유발하는 별도의 성과로 분류함. G1~G3, E1과 E5는 두 항목의 공통 요구와 실적 근거임.

| 성과 항목 | 근거 | 비교 대상의 확인 기능 | 과제 성과의 차별점 |
|---|---|---|---|
| Cave Ball의 분리 입력을 결합한 공 조작 | G2, G3, E1~E3, E5 | **MultiBall**은 인터랙티브 벽의 공 충돌 및 터치 감지와 신체 동작 추적을 제공함. [MultiBall Technology: Interactive Wall Technology](https://multi-ball.com/pages/technology) | 정면의 손 인식으로 가상 공의 색을 바꾸고 바닥 접촉으로 같은 공의 진행 방향을 바꿈. 두 입력을 좌우 벽의 색상별 벽돌 파괴 규칙에 함께 반영하여, 참가자가 색과 방향을 모두 조작하도록 구현함. |
| Cave Action의 참가자 간 공수 교대와 회피 | G2, E1, E4, E5 | **RoomAlive**는 벽과 바닥을 포함하는 공간 투사와 신체 동작 입력을 연구했으며, `Traps`는 가상 함정이 발사한 투사체를 참가자가 몸을 움직여 피하는 사례를 제시함. [RoomAlive, UIST 2014: Traps](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/paper2943.pdf) | 두 참가자가 공수를 교대하며 공격자의 벽면 입력 또는 점프가 상대의 회피 과제를 만듦. 방어자의 바닥 위치와 움직임이 피격 판정을 바꾸므로, 벽과 바닥에 배치한 입력이 참가자 간 대전에 연결됨. |

# 4 비교 수치와 검증 범위

| 항목 | 확인한 값과 조건 | 해석 범위 |
|---|---|---|
| 실시간 인터랙션 종류 | 과제 목표 2종. Cave Ball의 손 접촉에 따른 색 변경과 바닥 접촉에 따른 방향 변경의 동작을 기존 검토안에서 확인함. | 계획서의 자체평가 목표에 대한 근거이며, 경쟁 제품과 같은 기준으로 집계한 기능 수는 미확인임. |
| 공간 체험 시범 콘텐츠 제작 | 과제 목표 1개. Cave Ball과 Cave Action 제작 및 현장 시연은 기존 검토안에 기록됨. | 목표 달성 근거이며, 자체평가상의 최종 인정 건수는 현재 자료에서 별도로 확인되지 않음. |
| 출력면 구성 | MultiBall의 공개 구성은 인터랙티브 벽 1면임. Cave Ball과 Cave Action은 정면 및 좌우 벽 3면과 바닥 1면을 출력 대상으로 구성함. | 공개 구성과 구현 구성의 출력면 수 비교임. 투사면당 인식 면적, 인식 정확도 또는 처리량은 별도 지표임. |
| 반응 지연과 입력 반응 성공률 | 공통 조도, 입력 동작과 장비 조건에서 두 작품과 비교 대상의 측정 원자료를 확인하지 못함. | 처리율, 반응 지연, 인식률의 증감률은 미산정임. 확인된 차별점은 입력, 출력면과 콘텐츠 규칙의 결합 방식에 해당함. |

- 위키의 11월 5일 원문 파일 19개는 로컬 줄바꿈을 원본의 CRLF 형식으로 환산한 뒤 목록의 크기와 SHA-256이 일치함. 확인 범위는 코드의 정적 대조와 기존 현장 기록이며 이번 작업에서 Unity와 현장 장비의 재시험은 수행하지 않음. [구현 원자료: 확인 범위와 미확인 사항](<../../01_프로젝트/개발 자료/CaveBall/2026-11-05 구현 자료/2026-11-05 CaveBall 프로젝트 구현 원자료.md#4-확인-범위와-미확인-사항>)
