# 1 단계보고서 기재 문안

**㈜셀빅**

본 연구개발과제의 1단계에서 다중 프로젝터의 투사면과 중첩 구간을 사전에 검토할 수 있는 시뮬레이터와 센서 입력을 화면 좌표에 맞추는 공간 구축 도구를 개발하였음. 저조도 환경의 4면 미디어 케이브에서 Cave Ball과 Cave Action을 시연하여 벽면과 바닥의 입력을 실시간 콘텐츠 반응에 연결하는 기능을 확인하였음. 이를 통해 다면 투사 공간에서 관람객의 움직임을 체험에 반영하는 전시 콘텐츠를 개발할 수 있는 기반을 마련하였음. [연구개발과제의 수행 과정 및 수행 내용](<연구개발과제의 수행 과정 및 수행 내용.md#1-수행-과정-및-수행-내용>)

㈜셀빅의 별도 과제인 「한국실감」은 해외 납품용으로 소개된 한국문화 체험 사례임. 소개서에는 한국문화 콘텐츠 5종을 담은 키오스크 1대와 참여형 콘텐츠 3종을 담은 미디어 테이블 1대의 구성이 제시됨. 이 사례를 통해 관람객의 행동을 화면 반응에 연결하는 실감 콘텐츠 설계를 문화 학습과 창작 체험에 어떻게 적용할 수 있는지 구체적으로 검토할 수 있음. [K컬처실감 콘텐츠 소개서의 프로젝트와 납품 구성](<../../05_참고 자료/사례 조사/한국실감/K컬처실감 콘텐츠 소개서.md#2-프로젝트와-납품-구성>)

## 1.1 문화 콘텐츠 분야의 한국문화 체험 확대

「한국실감」은 한글, 음식, 한국화, K-POP과 고궁을 키오스크에서 소개하고, 미디어 테이블에서는 한글 이름 꾸미기, 한국 요리 만들기와 한국화 그리기를 제공하는 구성임. 키오스크에서 문화 정보를 살펴보고 테이블에서 도구를 조작해 직접 결과를 만드는 방식은 관람객 참여형 문화 전시를 설계하는 데 참고할 수 있음. 본 과제의 움직임 인식과 화면 반응 구현 사례는 이러한 체험을 향후 다면 투사 전시로 구성할 때 관람객의 행동과 화면 반응을 설계하는 데 활용할 수 있음. [K컬처실감 콘텐츠 소개서의 키오스크 콘텐츠](<../../05_참고 자료/사례 조사/한국실감/K컬처실감 콘텐츠 소개서.md#3-키오스크-콘텐츠>), [테이블 콘텐츠](<../../05_참고 자료/사례 조사/한국실감/K컬처실감 콘텐츠 소개서.md#4-테이블-콘텐츠>)

## 1.2 실감미디어 기술 분야의 입력과 화면 반응 설계

Cave Ball은 손의 위치가 화면 속 공과 겹치면 공의 색이 바뀌고, 바닥에서 감지한 접촉 위치에 따라 공의 진행 방향이 달라지도록 구현하였음. Cave Action은 점프, 벽면 터치와 위치 이동을 2인 대전의 공격과 회피에 연결하였음. 「한국실감」의 미디어 테이블은 자모 블록을 놓아 글자를 조합하거나 전용 부채를 움직여 조리 도구를 제어하는 체험을 제시함. 두 과제 모두 관람객의 행동을 화면 속 대상이나 진행 상태의 변화에 연결함. 본 과제에서 확인한 벽면과 바닥 입력의 연동 방식은 이러한 인터랙션을 여러 투사면에 걸쳐 구현하는 기술적 기반이 됨. [연구개발과제의 수행 과정 및 수행 내용 중 저조도 인터랙션 콘텐츠 개발](<연구개발과제의 수행 과정 및 수행 내용.md#12-저조도-조명-다중-투사-공간에서-단순한-인터랙션이-가능한-콘텐츠-개발>), [K컬처실감 콘텐츠 소개서의 테이블 콘텐츠](<../../05_참고 자료/사례 조사/한국실감/K컬처실감 콘텐츠 소개서.md#4-테이블-콘텐츠>)

## 1.3 디지털 창작 분야의 체험 결과물 연출

「한국실감」의 한국화 그리기는 관람객이 직접 그린 그림을 인공지능으로 한국화 스타일로 변환하고 풍등에 담아 화면에 띄우는 체험을 제시함. 키오스크 연계 포토타임은 문화 체험 후 사진을 촬영하고 콘텐츠 주제에 맞게 변환해 수령하는 기획 사례임. 본 과제에서 구현한 실시간 화면 반응에 이러한 결과물 연출을 연결하면, 관람객의 동작에 즉시 반응하는 체험을 참여자가 만든 결과를 전시에 표시하는 창작 체험으로 확장할 수 있음. ## 1.4 산업적 파급효과와 전시 공간 적용

본 과제의 시뮬레이터와 공간 구축 도구는 투사면, 프로젝터와 센서의 배치를 설치 전에 검토하고 설치 설정을 저장·복원할 수 있도록 구현하였음. 「한국실감」의 장비별 콘텐츠 구성은 전시 목적에 맞춰 안내, 조작 및 창작 기능을 각 기기에 배치하는 참고 사례임. 두 과제에서 얻은 설계 경험은 박물관, 문화시설과 체험관에 다면 투사형 공간을 추가할 때 장소별 장비 배치와 관람객 체험 흐름을 함께 검토하는 데 활용할 수 있음. 1단계에서 구현한 다면 투사와 실시간 입력 연동을 「한국실감」의 체험 구성과 함께 검토함으로써, 한국문화 전시의 후속 개발에서 장비 배치부터 관람객 참여와 결과물 연출까지 연계할 수 있는 방향을 제시함.
