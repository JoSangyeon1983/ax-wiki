- 이미지: PNG 28개 전체를 Pillow로 디코딩 검사하고 해시를 대조함. 대표 이미지 플레이_예시.png의 실제 열기와 화면 표시를 확인함. 이미지 내용과 라벨의 신규 검수는 수행하지 않음.

## 1.1 도구와 형식

- 새 헤더 도구의 동봉 테스트 40개 중 39개 통과, 환경에 따라 1개 제외됨.
- 검증용 루트와 실제 루트에서 헤더 번호, 계층과 인식 가능한 헤더 링크 검사 통과함. 최종 대상은 로그를 제외한 Markdown 37개임.
- 기획서 2개는 draft와 approval_status unverified임. sources는 비워두고 기존 인용은 related_documents로 남김. 기획 근거는 신규 채택 없이 비워둠.
- 사용자 편집본의 Markdown 이미지 문법은 원형 보존함. 기존 기록에는 통합 이미지 검수 도구의 전용 JSON 스키마가 없어 해당 도구 실행 대신 원본 해시와 실제 디코딩 검사를 수행함.

- 기계 대조 상세는 같은 폴더의 `검증 결과.json`에 기록함. 실제 전환 결과는 `이동 후 검증 결과.json`과 `적용 기록.json`에 보존함.
- 실제 적용 전 기준 이후 사용자 변경을 확인하고, 적용 후 실제 위키 루트에서 동일한 보존 및 연결 검사를 수행함.
