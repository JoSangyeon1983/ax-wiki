# 1 목적과 현재 상태

- 목적: 최신 무형문화유산 위키의 역할별 구조와 운영 규칙을 AX 자료에 맞게 적용하기 위한 임시 실행 계획임.
- 현재 요청 범위: 사용자의 시작 지시에 따라 S1~S6 구조 전환을 순차 실행함. 기획 내용의 신규 채택과 승인은 별개임.
- 현재 단계: S6 완료. 역할별 구조 전환 완료. 새 색인과 실제 검증 기록 정리, 이전 자료와 검증 사본의 보관 완료함.
- 다음 작업: 필요 시 기획 근거의 채택 및 승인 범위를 별도 검토함. 발표 피드백은 2026-11-04 사용자 삭제 지시로 사용 종료하여 이미지 복구 과제도 종결함.
- 문서 성격: 위키 운영 작업 기록임. 기획 내용의 출처나 채택 결정으로 사용하지 않으며, 정식 지식 폴더로 옮길 `target_folder`를 지정하지 않음.

## 1.1 작업 대상과 범위

| 구분 | 위치와 처리 범위 |
|---|---|
| 적용 대상 | `D:\Sangyeon\02_Task\2026\03_KOCCA\AX\01_Wiki` |
| 구조와 규정 참고 대상 | `D:\Sangyeon\02_Task\2026\03_KOCCA\30_무형문화유산\01_Wiki` |
| 가져올 대상 | 역할별 폴더 구조, 공통 운영 규정, 작성 형식과 검증 도구 |
| AX에 맞게 작성할 대상 | 색인, 파일별 분류, 규정의 적용 범위, 경로, 출처 관계와 작업 기록 |
| 가져오지 않을 대상 | 무형문화유산 과제의 기획, 원자료, 자산, 작업 로그, 개인 화면 상태와 콘텐츠 전용 설정 |

## 1.2 진행 기록 방법

- `[ ]`는 미완료, `[x]`는 완료임. 진행 중과 보류는 단계 현황 및 보류 사항 표에 기록함. 일부만 끝난 항목은 체크하지 않음.
- 체크 완료 시 실행 기록에 실제 시각, 대상, 검증 결과와 증거 위치 기록함. 실행하지 않은 점검은 완료로 표시하지 않음.
- 단계 식별자 S0~S6와 세부 작업 식별자는 유지함. 헤더 번호가 바뀌어도 작업의 동일성을 추적함.
- 실행 요청으로 부여된 범위 안에서는 단계를 순서대로 진행함. 매 항목에 추가 승인을 요구하지 않으며, 해소할 수 없는 규정 충돌과 기획 채택 결정은 해당 작업만 보류함.
- 후속 세션은 현재 적용 중인 AGENTS.md와 규정, 본 문서의 단계 현황, 최근 실행 기록을 확인한 뒤 첫 미완료 항목부터 재개함. 이전 체크 항목은 변경 영향이 있을 때 재검증함.

- 최신 위키는 참고 원본으로만 읽음. AX 규정을 정리하기 위해 최신 위키를 함께 수정하지 않음.

- Git 커밋과 원격 반영 여부는 별도 작업 범위로 관리함. 구조 전환 결과의 검증을 커밋이나 푸시로 대체하지 않음.
