# 1 작업 범위

- 사용자 요청: 2026-11-05 코드 분석을 바탕으로 CaveBall과 CaveAction의 콘셉트를 각각 작성함.
- 두 문서의 H1은 개요, 전체 플로우와 주요 시스템으로 구성함.
- 기존 Cave Super Ball 콘셉트 초안을 갱신하고 Cave Action 콘셉트 기획서를 새로 작성함.

- [자료 준비 도구](<자료 준비.py>): 선택한 원문 19개를 보관하고 SHA-256 일치 확인 및 파일 목록 기록.

# 3 보존과 영향 확인

- [Cave Super Ball 기존 초안](<Cave Super Ball 기존 초안.txt>)은 변경 전 내용 보존용임. 현재 기획 기준으로 사용하지 않음.
- 기존 상세 기획서가 연결하는 콘셉트 파일 경로와 개요 앵커를 유지함. 상세 기획서의 콘텐츠 정의와 통합 입력 검증 목적은 수정한 콘셉트와 대조함.
- 기존 상세 기획서의 기기 수치와 나머지 본문은 이번 갱신 범위에 포함하지 않음. 상세 기획서 전체의 검증이나 승인을 의미하지 않음.
- 외부 Unity 프로젝트는 수정하지 않으며, 콘셉트 승인과 운영 수치 확정은 수행하지 않음.
