# 2. 기관별 1차연도 목표 및 진행상황

## 2.1 경희대 산학협력단

### 2.1.1 1차연도 목표

| 번호  | 목표                                   | 연계                 |

| 1   | 마이크로디그리 수업을 통한 인재 양성 및 콘텐츠 제작        | 전체 (교육과정)          |
| 2   | 촉각 실감 AX 융합 콘텐츠의 지속적 방문/몰입 메커니즘 연구   | 월러스코 디자인랩          |

| 4   | 다양한 분야 적용을 위한 시촉각 AX 융합 콘텐츠 기획개발 연구  | 셀빅, 월러스코 디자인랩 (양쪽) |

| 6   | 텍스트 프롬프트를 사용한 자동 에셋 생성 기술 개발         | 로블록스               |

### 2.1.2 연구 진행상황

개발 목표 대비 진행 내용을 정리함.

- **지속적 방문 메커니즘 연구**: 라이프로깅 방식을 활용한 LBE(로케이션 베이스드 엔터테인먼트)를 통해 지속적 방문 메커니즘 연구 진행 중
- **관객 동선 상호작용 연구**: 공간 기반 관객 동선을 고려한 상호작용 연구. 팀 제작으로 초안 연구를 목표로 진행 중
- **촉각 AX 융합 콘텐츠 기획개발**: 현재 5개 진행 중, 1개 추가 개발 예정
- **AX 융합 콘텐츠 사용성 평가**: 위 콘텐츠를 바탕으로 사용성 평가와 분석 진행 예정
- **자동 에셋 생성 기술**: 텍스트 프롬프트를 사용한 자동 생성 기술을 로블록스 스튜디오와 연동해 개발 예정
- **연구 성과의 활용 연계**: 경희대 연구물(예: 국궁 콘텐츠, 몰입형 독서 플랫폼, 미디어아트 등 스탠드얼론 콘텐츠)을 셀빅/월러스코의 전시나 콘텐츠에 주제에 맞게 변형해 활용하면 공동 실적이 됨. 진행 결과는 논문/문서로 공유 예정

### 2.1.3 정량 성과목표 현황

회의 발언 기준 진행 현황임. 확정 실적이 아니라 진행 중 수치임.

| 국내 특허 출원 | 원래 1건 예정, 현재 3건 준비 중 |

## 2.2 셀빅

### 2.2.1 1차연도 목표

- 다중 프로젝터를 활용한 콘텐츠 시뮬레이션 기술 개발
- 저조도, 도형 다중 투사 공간에서 단순한 인터랙션이 가능한 콘텐츠 개발

### 2.2.2 연차별 목표

- **1년차**: 바닥면에 놓인 사물을 인식해 프로젝션 매핑을 하는 케이브 매핑 콘텐츠
- **2년차**: 실제 탄환을 발사하는 너프건 또는 적외선 총을 활용한 슈팅 콘텐츠. 바닥 물체 인식을 엄폐물 등으로 활용하는 아이디어 검토
- **3년차**: 사람과 사람이 든 사물을 인식해 콘텐츠와 반응하는 콘텐츠

### 2.2.3 1차연도 정량 목표

- **성능 지표**: 원래 3차연도 공인 시험으로 설정됨. 1차연도부터 공인을 넣어달라는 요청에 따라 변동 여부를 셀빅이 확인 예정. 
- **실시간 인터랙션 종류 4가지**:
	- 사람 모션 인식
	- 바닥면 사물 인식
	- 벽면 레이저 센서 터치
	- 총기 인식 (너프건 또는 적외선 총)
- **시범 콘텐츠 제작**: 기본적으로 수업(PBL) 연계로 진행하되, 1년차는 수업 연계가 어려워 셀빅이 자체 데모를 제작
- **기타 성과**: 시제품과 소프트웨어 등록은 매년 1개씩. 3년차에 특허 출원, 공인인증 시험, 사업화 배치

### 2.2.4 보유 기술 리뷰

보유 기술을 순차 시연하며 설명함. 대부분 테이블 또는 케이브 공간 환경임.

- **적외선 마커 기반 물체 인식**: 나무 블록 안에 적외선 마커를 넣어 올려놓으면 물체를 인식해 프로젝션 매핑을 띄움. 초기에 코딩 교육용으로 활용했으나 교구 제작이 복잡해 상용화까지는 가지 못함
- **물체 모양 인식**: 컵과 접시를 다르게 인식해 각기 다른 이펙트를 주는 테이블 콘텐츠. 물체를 놓으면 오브젝트가 반응(연결, 회피, 추적)하는 방식
- **벽면 오브젝트 인식과 적외선 램프**: 적외선 손전등을 비추면 위치를 인식해 물줄기를 뿌리거나 레이저를 쏘는 콘텐츠. 벽면 터치와 공 던지기 활용도 있음
- **너프건 슈팅**: 던파 행사에서 사용. 너프건 총알을 발사하면 벽면에서 인식하는 슈팅 게임. 총알이 튀어 케이브 공간에서는 사용이 까다로워 적외선 총 대안을 검토 중
- **바닥 매핑**: 퀴즈 콘텐츠 위주에서 최근 외국인/아이돌 대상 콘텐츠로 확장. AI로 뽑은 3면 영상 몰입형 콘텐츠로, 사용자가 춤을 따라 하면 인식해 마지막에 아이돌과 사진을 찍는 콘셉트

### 2.2.5 사업 방향 전환

- **방향 전환**: 키즈/유아용 콘텐츠 중심에서, AI 발달에 맞춰 전시/관람 콘텐츠로 컨셉을 확장 중. 키즈 사업은 유지하되 병행
- **주력 공간**: 4m에서 6m 규모의 케이브 공간. 최근 늘어난 몰입형 전시 공간을 겨냥
- **콘텐츠화 검토**: 공간을 활용한 착시 연출 등 재미있는 장면을 콘텐츠화 검토 중
- **협업 아이디어**:
	- 우탁 교수 제안으로, 노즐 등에 진동 반응을 주는 하드웨어 협업 가능성 논의
	- PBL 수업, 워크샵, 해커톤에서 AI로 리소스까지 만들어 적용하는 아이디어를 함께 발전
- 기술 소개 자료는 회의 후 메일로 공유 예정

## 2.3 월러스코 디자인랩

### 2.3.1 1차연도 목표

- 미디어를 활용한 시청각 기반 XR 콘텐츠 개발
- XR 콘텐츠 프로토타입 구축

### 2.3.2 진행 현황과 포트폴리오

준비 미비로 소개 위주로 진행하고, 콘텐츠는 추후 영상으로 공유하기로 함.

- **진행 방향**: 올해는 실감 구간 위주로 공간 작업 진행 중. 관련 콘텐츠는 추후 영상 공유
- **곡면 디스플레이**: 평면 디스플레이가 아니라 곡면으로 디스플레이를 구성하는 작업 진행 중
- **울산 장생포 사례**: 33m 길이 터널을 내부와 외부 모두 화면으로 구성 완료. 반응이 좋아 관련 영상을 추후 공유 예정
- **협업 방향**: 월러스코가 지속적으로 사업을 수주하므로, 수주 사업에 공동 아이디어를 반영하는 방식이 최선. 수주 건이 있을 때 미리 공유하면 경희대가 맞춤

# 3. 프로젝트 진행 시 주의사항

## 3.1 공동연구 실적 문서화

본 사업은 각 기관이 개별 연구를 수행하되, 주관기관(경희대)과의 연계로 공동 연구개발한 것으로 증빙돼야 함.

- **개별 개발 + 연계 증빙**: 셀빅, 월러스코가 각자 목표를 수행하되, 결과물이 경희대와의 공동 연구개발로 보이도록 문서를 미리 준비함
- **크로스 문서화**: 예를 들어 셀빅이 XR 콘텐츠를 개발하면, 경희대가 기획 일부를 작성한 것처럼 대응 기획서를 만들어 두고 이를 기반으로 발전시킨 형태로 문서화함
- **기획서/보고서 사전 준비**: 기관이 연구를 진행할 때 대략의 내용으로 기획서와 보고서를 경희대에 보내면, 경희대가 이를 작성해 회신함. 양쪽 기관 모두의 실적이 됨
- **사용성 테스트는 경희대 담당**: 기관이 만든 콘텐츠의 사용성 테스트가 필요하면, 인원 규모를 지정해 경희대에 요청함. 경희대가 설문/인터뷰 등 방법론을 적용해 진행함
- **현장 데이터 수집**: 기관 콘텐츠가 현장(예: 지자체 전시)에 구축돼 있고 해당 기관이 승인하면, 경희대가 기간을 잡아 실제 관람객 대상으로 사용성 평가를 진행할 수 있음

## 3.2 성과 확보와 사사

우탁 교수가 참여기업의 성과 확보 방향을 조언함.

- **셀빅**: 소프트웨어를 많이 개발하므로, 소프트웨어 등록 시 본 과제 사사를 표기함. 더블 사사까지 인정되는 것으로 파악됨. 콘진원은 특허보다 소프트웨어 등록 실적을 선호함
- **월러스코**: 특허를 많이 출원하므로, 특허 출원 시 본 과제 사사를 표기함
- **사사 공유**: 과제명 또는 사사를 넣으면 실적으로 인정됨. 각 기관은 사사 정보를 경희대와 공유함
- **기본 수치 + 플러스알파**: 기본 수치는 경희대가 최대한 채우되, 전체 실적은 목표 대비 플러스로 나와야 함

## 3.3 기술이전과 사업화 성과 처리

KOCCA 컨설팅에서 경희대와 참여기관이 공동 개발해 사업화한 성과를 증빙하도록 요구함(기술 이전 취지).

- **직접 기술 이전은 배제**: 학교의 기술 이전은 기관 간 자금 이동을 수반함. 셀빅 정영균 상무 의견으로, 상위 기관 감사에서 내부 거래로 걸릴 가능성이 커 원천적으로 진행하지 않기로 함
- **대안: 기술 활용 증빙**:
	- 경희대 연구물을 기관이 전시/콘텐츠에 활용하고, 활용 사진과 공유 문서를 첨부
	- 경희대가 기획한 것을 셀빅이 제작한 형태로 기술 활용 동의서 또는 기술 활용 보고서를 작성해 제출
- **최선은 공동 연구 기반 매출 증빙**:
	- 셀빅이 공동 기획물을 제작해 납품하면 납품 매출(예: 1천만 원)을 증빙으로 함께 제출
	- 월러스코가 수주한 과제(예: 수억 원 규모)에 공동 개발물을 활용하면 기술 활용 실적이 됨
- **위탁도 인정**: 셀빅/월러스코가 수주한 별도 과제에 경희대로 위탁을 주면, 공동 개발물이 활용된 것으로 KOCCA가 실적 인정 의사를 내비침

## 3.4 협약 변경

협약 변경 항목을 통보 항목과 승인 항목으로 구분함.

- **통보 항목** (협약 변경으로 바로 진행 가능):
	- 연구원 변경
	- 참여 인원수 변경 (추가/축소 모두 포함, 단 연구책임자는 제외)
	- 비목 금액을 낮추는 변경 (대부분 통보성, 규정 확인 권장)
- **승인 항목** (공문과 내용을 경희대로 보내면 경희대가 진행):
	- 비목 금액을 올리는 변경
	- 성과 목표 변경
- 변경 요청 시 공문을 첨부해 경희대에 전달하면 경희대가 파일을 공유함

## 3.5 IRIS 성과 등록과 공인인증

- **KOCCA 과제 담당자**: 권영환. 연락이 잘 닿지 않으므로, 담당자보다 경희대에 먼저 연락하면 처리가 빠름
- **IRIS 등록 절차**: IRIS 접속 → 성과 목록 페이지(과제 수행) → 콘진원 과제 검색 → 과제별 성과 항목에서 등록 버튼 → 필수 내용 작성 + 증빙 자료 업로드 → 승인
- **기타 성과 처리**: 목록에 없는 항목(보고서 등)은 기타 성과로 등록
- **제품 인증(공인인증)**:
	- 컨설팅 요청으로 실적 검증이 공인인증기관 인증으로 변경됨
	- 1차연도부터 공인인증을 넣도록 요구됨. 원래 3차연도만 하던 항목도 2차연도 등으로 앞당겨 진행하라는 컨설팅이 있었음
	- 시간이 걸리므로 미리 준비. 자체 평가는 외부 전문가 자문비를 써서 자문/검증 보고서를 만들고, 이를 바탕으로 공인인증을 받는 흐름
- **IRIS 문의 요령**: 콘진원은 성과 등록 담당이 아니므로 IRIS에 문의. IRIS는 외부 기관에 검토를 위탁함. 문제 발생 시 검토 이력과 규정을 확인하고, 대부분 서류 누락이 원인이므로 부족한 서류를 보완하면 등록됨

## 3.6 연구노트 작성

- **작성 시점**: 과제 시작이 4월이므로 4월부터 작성
- **학교**: 40% 참여율 기준으로 주 2쪽 정도 작성
- **기업**: 공동 노트 1권에 참여 연구원들이 분할 작성. 연 20~30페이지 규모 (셀빅 기준)
- **검수 유의**: 일반적인 내용이라도 이 프로젝트 연구에 어떻게 썼는지 서술을 덧붙여야 함. 실제 설계도나 디자인 작업 이미지를 넣으면 좋음. 전자 노트 사용 시 날짜가 자동 기록돼 매일 작성이 강제되므로 권장(기업 대상)

## 3.7 사업 방향성과 심사 대응

우탁 교수가 사업 방향과 최근 심사 분위기를 정리함.

- **사업 방향성**: 학교(연구소)가 개발한 것을 기업이 실제 적용하고, 기업의 기술 노하우를 학생에게 전수하며, 학생이 이를 기반으로 콘텐츠를 연구하는 구조. 기존에 하던 사업과 방향성이 다름
- **1차연도 중요성**: 1차연도 첫 허들을 넘으면 2차연도는 수월하고, 마지막 연도는 정량 수치를 채우면 됨
- **심사 분위기**: 최근 최종 결과물 오류에 민감함. 연구비 삭감 과제는 퀄리티를 엄격히 심사함. 과제 종료 후 5년간 실적 발생 여부를 계속 추적함(셀빅은 3년 전 종료 과제 성과 감사 사례 경험)
- **실적 기조**: 전체 실적표는 목표 대비 플러스알파로 진행한다는 마인드로 임함

# 4. 교육과정: PBL 운영

## 4.1 PBL 3과목 기관 연계

2027년 개설 예정인 PBL(문제 기반 학습) 수업은 3과목이며, 각 과목이 특정 기관과 연계됨.

| 과목          | 연계                |
| ----------- | ----------------- |
| 실감 AX 기술    | 로블록스 (다음 학기에도 진행) |
| 실감 AX 융합 기획 | 셀빅                |
| 메타버스 실감 PBL | 월러스코 디자인랩         |

## 4.2 강의계획서와 참여 스케줄

로블록스와 진행하는 강의계획서 프레임을 두 기관에도 공통 적용함. 주제만 각 기관이 원하는 것으로 교체함.

- **공통 프레임**: 개요(수요 기업), 제시한 문제, 오리엔테이션 구조는 공통. 수요 기업 자리에 셀빅/월러스코가 들어감
- **기관 참여 횟수**: 한 학기 기준 최소 6회에서 8회 참여. 대부분 학생 발표를 듣고 피드백을 주는 구성
- **주요 참여 지점**:
	- 2주차: 기업 소개와 주제 발표 (기업이 방문해 "이런 것을 개발했으면 좋겠다"는 주제를 강의식으로 제시)
	- 저작 툴 수업: 기관 기술 이해가 필요하면 2회 정도 배정 가능 (로블록스 사례에서 자체 저작 툴 수업 2회 편성)
	- 현장 실습 1회: 기업 본사 방문 또는 기업 행사 초청 (로블록스는 부산 행사에 학생 초청). 학생이 현장을 직접 보는 것이 중요
	- 13주/14주/16주차: 발표회
- **구성 자율**: 기관은 강연, 학생 발표 기반 피드백, 현장 실습 중 선택해 구성 가능

## 4.3 강의 운영과 인계

- **강의 운영 방식**: 대학 강의는 기본 3시간. 3시간을 모두 진행할 필요는 없고 1시간 10분씩 나눠 휴식을 두고 운영 가능
- **작성 시기**: 2학기 수업(9월 시작)은 5~6월에 강의계획서를 작성함. 1학기 수업은 전년도 11~12월에 작성함
- **강의계획서 공유**: 경희대가 강의계획서를 문서로 각 기관에 공유하고, 기관은 반영할 의견을 회신함. 수업 진행 전 스케줄을 맞춤
- **인계**: 우탁 교수는 2027년 안식년으로 강의를 하지 않음. 강의계획서까지 작성해 후배 교수에게 인계함. 우탁 교수 지도로 박사 과정을 마친 정윤아 박사가 연구교수로 합류해 강의를 맡을 예정임

# 5. KOCCA 컨설팅 요구: 특강, 워크샵, 해커톤

KOCCA 컨설팅 당시 요구사항으로, 경희대뿐 아니라 참여기업 연구원 대상 특강과 체험 활동을 진행해야 함.

## 5.1 특강 및 체험 활동

- **대상과 시기**: 참여기업 연구원 대상 포함. 8월 말에서 9월에 진행 예정
- **워크샵 주기**: 제안서에 명시된 대로 학기마다 1회 진행

## 5.2 워크샵과 해커톤 배정

- **기업별 배정**:
	- 올해: 로블록스와 워크샵 3회 + 각 워크샵마다 해커톤 1회씩 총 3회
	- 내년: 셀빅 최소 1회, 월러스코 디자인랩 최소 1회
- **구성 예시** (로블록스 기준):
	- 워크샵: 두 기관이 보유한 새 기술을 3시간 기준 4회로 강의
	- 해커톤: 5회차에 해당 기술/환경(예: XR 환경)을 활용하는 주제를 제시하고 학생들이 1박 2일간 콘텐츠를 제작
	- 분반: 학생이 많아 1차/2차로 나눔. 1차는 월요일부터 금요일까지 스트레이트, 2차는 매주 금토 반복, 마지막 날 1박 2일 해커톤
- **실적 인정 전망**: 올해 로블록스 워크샵 3회와 해커톤 3회로 예정 실적에 플러스 확보 예상. 다만 KOCCA가 묶어서 카운팅할 가능성이 있어 최소 플러스 1 수준으로 봄

# 6. 결정사항

- 각 기관은 개별 개발물을 경희대와의 공동 연구개발로 문서화함 (크로스 기획서/보고서 사전 준비)
- 직접 기술 이전(자금 이동)은 내부 거래 감사 리스크로 진행하지 않음. 기술 활용 증빙과 공동 매출 증빙으로 대체함
- 사용성 테스트는 경희대가 담당하며, 기관이 사전 요청함
- PBL 강의계획서는 로블록스 프레임을 두 기관에 공통 적용하고 주제만 교체함
- 제품 인증은 공인인증기관 인증으로 처리하며 1차연도부터 준비함
- 연구노트는 4월부터 작성함
