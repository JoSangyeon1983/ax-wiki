# 1 현재 상태

- 별도로 만든 독립 사용과 전달용 파일은 현재 등록되지 않음. 기존 초안과 제작 자산은 실제 관리 위치에서 열람함.

# 2 현재 작업과 자산

- [중간발표 1020 피드백 초안](<../../90_작업 공간/중간발표 1020 피드백/현재 정본/중간발표 1020.md>): draft 상태인 현재 편집 기준 문서임.
- [이관 이미지 관리 기록](<../../06_자산/이미지/이관 이미지 관리 기록.md>): PNG 28개의 제작 및 원문 삽화 자료를 관리함.
- [콘텐츠별 전체 플로우](<../../06_자산/도표/CaveBall 전체 플로우/전체 플로우 제작 기록.md>): 콘셉트 본문에 삽입한 재사용 도표 자산. draw.io 편집 XML 2개와 PNG 2개가 존재하며 내용과 파일 구조 및 이미지 표시를 검토함. 콘셉트 승인 대기 상태 유지.
- [Cave Super Ball 개요 이미지](<../../06_자산/이미지/Cave Super Ball/Cave Super Ball 이미지 작업 기록.md>): 1448 × 1086 px의 4:3 PNG가 존재하며 개요에 HTML로 삽입함. 문자열과 표현 검수 완료, 콘셉트 승인 대기 상태 유지.
- [Cave Action 개요 이미지](<../../06_자산/이미지/Cave Action/Cave Action 이미지 작업 기록.md>): 1448 × 1086 px의 4:3 PNG가 존재하며 개요에 HTML로 삽입함. 문자열과 표현 검수 완료, 콘셉트 승인 대기 상태 유지.

# 3 등록 기준

- 실제 전달용 파일을 작성한 경우 원본과 기준 시점, 검토 및 승인 상태와 실물 상태를 함께 기록함. 파일을 복제하여 산출물 수를 늘리지 않음.
